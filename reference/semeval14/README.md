## Inputs

- Data: `examples/restaurant.tsv` (SemEval-2014 restaurant sentences with aspect and sentiment), sha256 `f7f5a37ff6ed449c73f2291505ce615e443527a6423573ceaaa751f2e47cea50`
- Embedding: GloVe 840B, 300d (https://nlp.stanford.edu/projects/glove/), converted to word2vec text format with
  `gensim.scripts.glove2word2vec` and the header set to `2196016 300` (see 'Download embedding' in the README)
  - `glove.840B.300d.w2vformat.txt` sha256 `34fead1da1f208a3073ea7e2079ec701bf8931f2b343781679944acb56fcab2f`
  - `glove.840B.300d.zip` sha256 `c06db255e65095393609f19a4cfca20bf3a71e20cc53e892aafa490347e3849f`
- Axes: WordNet adjective antonyms (`frameaxis/axes/wordnet_antonyms.tsv`, 1,828 pairs); 1,621 are present in the embedding.

## Parameters

- Unit: each sentence is a document; `min_freq = 1`; NLTK English stopwords removed; the aspect word and its
  plural (`aspect`, `aspect + "s"`) removed from each sentence (`to_filter`).
- Bias: frequency-weighted mean cosine score per axis (`compute_document_mean_with_tf`).
- Intensity: second moment around the corpus mean (`compute_document_second_moment_with_tf`).
- Rows: 3,705 of 3,713 sentences produced a row in the bias table, 3,705 in the intensity table
  (notebook 1 skips a sentence when no word survives filtering).
- Null: N = 10000 random subsets per aspect × sentiment cell, each the size of the cell, drawn without replacement
  from the whole table, seed 2021.
- Test: two-sided p = (1 + #{|null - mean(null)| >= |observed - mean(null)|}) / (N + 1); Benjamini-Hochberg
  across all axes within each cell; significant when q <= 0.05.

## Files

- `<mode>/significant_axes_<aspect>_<sentiment>.tsv`: every axis with `diff_a_b` (observed minus null mean),
  `p`, `q`, and `p_2021` (the rule used before #13, for comparison only).
- `<mode>/effect_size_significant_axes_<aspect>_<sentiment>.tsv`: axes with q <= 0.05, by `|diff_a_b|`.
- `<mode>/cell_means.tsv`: observed mean per axis for each aspect × sentiment cell.
- `CHANGES.md`: how the corrected test differs from the tables the notebooks produced before #13.
